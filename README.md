# Compiler App

A mini compiler built with C# and Windows Forms as part of the Compiler Design course (CS321) at El-Shorouk Academy.

## Features
- Lexical analysis (tokenizer)
- Syntax analysis (parser)
- Windows Forms GUI

## Tech Stack
- **C#** - Programming language
- **.NET** - Framework
- **Windows Forms** - GUI

## How to Run
1. Clone the repo
2. Open `compiler app.sln` in Visual Studio
3. Press `F5` to run

## Course
Compiler Design (CS321) - El-Shorouk Academy
